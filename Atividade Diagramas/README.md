# Exercícios

Agora iremos criar o modelo conceitual e transformar em modelo lógico.

## Cenário 1: Sistema de Vendas Online
Um sistema de vendas online para uma loja de eletrônicos.  
O sistema permite que os clientes visualizem os produtos disponíveis, adicionem itens ao carrinho de compras e façam pedidos.  
Os clientes devem se registrar no sistema para realizar compras.

## Cenário 2: Sistema Acadêmico
Um sistema acadêmico para uma universidade.  
O sistema permite o cadastro de alunos, professores e disciplinas.  
Os alunos podem se matricular em disciplinas, os professores podem atribuir notas e o sistema gera relatórios de desempenho dos alunos.

## Cenário 3: Sistema de Biblioteca
Um sistema de gerenciamento de biblioteca para uma instituição educacional.  
O sistema permite o cadastro de livros, autores e editoras.  
Os funcionários podem registrar empréstimos e devoluções de livros, além de gerar relatórios de estoque e movimentação.

## Cenário 4: Sistema de Hotelaria
Um sistema de hotelaria para um hotel de luxo.  
O sistema permite o cadastro de hóspedes, quartos e reservas.  
Os hóspedes podem fazer reservas online, solicitar serviços adicionais e efetuar o pagamento das estadias.

## Cenário 5: Rede Social
Uma rede social para compartilhamento de conteúdo entre usuários.  
O sistema permite que os usuários criem perfis, façam postagens, comentem em publicações de outros usuários e interajam por meio de mensagens privadas.

## Cenário 6: Sistema de RH
Um sistema de gestão de recursos humanos para uma empresa.  
O sistema permite o cadastro de funcionários, departamentos e projetos.  
Os funcionários podem solicitar férias, registrar horas trabalhadas e acessar informações sobre benefícios e folha de pagamento.

## Cenário 7: Sistema de Delivery de Comida
Um sistema de delivery de comida para restaurantes locais.  
O sistema permite que os clientes façam pedidos online, visualizem o cardápio dos restaurantes parceiros, acompanhem o status dos pedidos e avaliem a experiência de entrega.
