# Desafio 1

Você foi contratado por uma corporação que está planejando desenvolver um novo sistema para uma imobiliária. Para tanto, será necessário identificar as entidades, atributos e os relacionamentos envolvidos no sistema para que os programadores consigam criar o software conforme as necessidades da empresa.

As regras da imobiliária são:

1. Cada proprietário pode possuir uma ou mais residências.
2. A imobiliária possui diversos corretores.
3. Cada cliente possui um corretor exclusivo.
4. Cada cliente pode alugar um ou mais imóveis.

# Desafio 2

Você foi contratado por uma empresa que está desenvolvendo um sistema de gerenciamento de biblioteca. O objetivo é identificar as entidades, atributos e os relacionamentos necessários para que o sistema atenda às necessidades da biblioteca.

As regras da biblioteca são:

1. Cada livro pode ser emprestado para apenas um leitor por vez.
2. Um leitor pode emprestar vários livros ao mesmo tempo.
3. Cada livro pertence a uma única categoria.
4. A biblioteca possui vários funcionários que realizam o atendimento aos leitores.

# Desafio 4

Você foi contratado por uma rede de academias que deseja desenvolver um sistema para gerenciar o relacionamento com seus clientes e as atividades físicas oferecidas. O objetivo é identificar as entidades, atributos e os relacionamentos necessários para que o sistema atenda às necessidades da academia.

As regras da academia são:

1. Cada cliente pode se matricular em várias atividades físicas.
2. Cada atividade física pode ser conduzida por um ou mais instrutores.
3. Um instrutor pode conduzir várias atividades físicas.
4. Cada cliente possui um plano de assinatura específico.
